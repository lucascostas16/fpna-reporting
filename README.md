# FP&A Reporting Pack

This project focuses on the design of a financial reporting pack aimed at supporting management control and decision making.

---

## Objectives
- Build a structured P&L reporting model
- Analyze budget vs actual deviations
- Track financial KPIs
- Provide variance explanations with business insight

---

## Scope
The reporting pack includes:
- Income statement structure
- Budget vs actual analysis
- Monthly and YTD KPIs
- Visual dashboards for management reporting

---

## Tools
- Power BI
- Excel
- SQL

---

## Current status
Initial structure defined. Data model and dashboards under development.
